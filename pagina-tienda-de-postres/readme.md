# 🖼️ Tienda de Pósters - Página Web en Desarrollo

¡Bienvenido al repositorio oficial de la página web para nuestra tienda de pósters!  
Este proyecto tiene como objetivo crear una plataforma atractiva, funcional y responsiva donde los usuarios puedan explorar y adquirir una variedad de pósters de alta calidad.

## 🚧 Estado del Proyecto

**En desarrollo**: Actualmente estamos trabajando en el diseño, la estructura y las funcionalidades básicas del sitio.  
Actualizaciones y mejoras se irán agregando progresivamente.

## 🛍️ Sobre la Tienda

Nuestra tienda se especializa en ofrecer pósters únicos y creativos para decoración de interiores.  
Contamos con colecciones temáticas, arte digital, ilustraciones minimalistas y mucho más.
